# fx-app

Local Astro app that converts an amount between currencies using live [Frankfurter](https://frankfurter.dev/) rates. No API key.

## Run

Needs Node.js 18+ and internet access for rates.

```bash
cd ~/fx-app
npm install
npm run dev
```

Open the URL Astro prints (usually `http://localhost:4321`).

Default conversion is **USD → PHP**. Rates are public reference data, not bank quotes.
